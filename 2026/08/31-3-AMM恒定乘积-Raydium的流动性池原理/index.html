AMM 恒定乘积：Raydium 的流动性池原理

去中心化做市，Solana 链上资产换手的核心引擎

1. 为什么链上资产需要去中心化交易所

当一个资产从 Bonding Curve 迁移到 Raydium，意味着它正式进入了一个完全自由的市场——任何人都可以随时买卖，价格由供需实时决定，不再有联合曲线的数学公式约束。

Raydium 是 Solana 生态里最主流的 AMM（自动做市商）去中心化交易所。它为链上资产提供了两个关键能力：流动性和价格发现。流动性由流动性提供者（LP）注入——他们把自己的 SOL 和代币按比例存入资金池，换取 LP Token 作为凭证；价格则由 AMM 的恒定乘积公式 x × y = k 自动计算。

AMM 恒定乘积公式的直觉：
资金池里两种资产数量的乘积在每次交易后保持不变。如果有人买走了代币（池子里代币变少），公式要求 SOL 的数量等比例增加——即代币相对 SOL 的价格上升。这就是去中心化交易所上”买盘推高价格、卖盘压低价格”的数学本质。

2. 流动性池的结构与运作

Raydium 的流动性池由两个核心账户组成：一个是存放 SOL 的账户，一个是存放代币的账户。池子记录这两种资产的数量，以及当前价格。LP 的份额由他存入两种资产的价值占比决定。

当用户想买入代币时，他往池子里打入 SOL，换出代币。池子自动计算新的价格。如果买入量很大，池子里 SOL 数量大幅增加、代币数量大幅减少，价格就会急剧上升——这就是链上资产经常出现的”剧烈波动”现象，背后是 AMM 的价格机制在起作用。

3. 链上资产价格的实时性

Raydium 的价格更新是完全链上的。每笔交易都会更新池子里两种资产的数量，进而影响下一笔交易的价格。这和中心化交易所的订单簿撮合完全不同——在去中心化交易所上，没有”挂单”这个概念，只有”即时成交”，价格由交易量直接驱动。

对于链上社区资产来说，这种机制有放大效应。当某个资产出现外部热点（社区 FOMO、名人效应），大量买盘同时涌入池子，价格在几秒内可能翻几十倍。LP（流动性提供者）在提供流动性的同时，实际上在为这种波动性”做市”——他们赚取交易手续费，但也要承担资产价格归零时的无常损失。

💰 LP 把 SOL + 代币存入池子，持有 LP Token 作为凭证 ↓

📊 买家打入 SOL，换出代币，池子数量变化驱动价格上升 ↓

📈 价格上涨吸引更多买家，更多买入进一步推高价格（正反馈） ↓

💸 卖家换入 SOL，价格下跌，LP 赚取手续费，承受无常损失

4. 为什么 Raydium 是链上资产的主要交易场所

Raydium 在 Solana 链上资产生态中占据主导地位，有几个结构性的原因。第一，Solana 的交易速度让 Raydium 的 AMM 报价几乎和中心化交易所一样快，降低了”三明治交易”的利润空间。第二，Raydium 直接接入了 Solana 的订单簿基础设施，为部分池子提供了额外的订单簿流动性。第三，Bonding Curve 的迁移机制默认把流动性注入 Raydium，形成了天然的生态锁定。

下篇预告

Solana 上有专门的交易机器人——它们能比人类快几毫秒抢到最早期的资产。这是怎么做到的？

✅ AMM 用恒定乘积公式 x×y=k 自动计算价格

✅ 买入代币 → 池子 SOL 多、代币少 → 价格上升

✅ 卖出代币 → 池子 SOL 少、代币多 → 价格下跌

✅ LP 提供流动性赚手续费，但承担资产归零时的无常损失

✅ Raydium 接通迁移机制，成为 Solana 链上资产的主要交易场所
