美债代币化：把美国国债份额搬上链

发表于2026-08-04|更新于2026-09-02|RWA代币化
|总字数:1.9k|阅读时长:6分钟|浏览量:

Ondo、Hashport 如何用区块链封装国债持仓

1. 美债代币化到底封装了什么

美国国债是全球流动性最好的美元资产之一，但它传统上只能通过银行或基金持有，且在交易时段外无法操作。美债代币化要做的，是把”持有国债”这件事用区块链重新封装一遍：项目方把国债买进一个 SPV（特殊目的载体）基金，然后把基金份额代币化；持有链上 Token 的人，拿到的是可交易、可合约交互、按规则累积票息的份额凭证。

这里的核心不是”把国债搬上链”，而是”把国债的操作逻辑搬到链上”。底层国债仍由托管方在现实金融系统里保管，链上发生的一切——转让、计息、赎回——都是对那份底层权益的映射。理解这个分层，是理解所有 RWA 产品的钥匙。

核心结构：

底层资产 = 真实美国国债（由 SPV 持有）
链上 Token = 基金份额的权益凭证
票息来源 = 国债本身的票面利息

持有者持有的是”有国债背书的份额”，其价值锚定底层资产净值。

2. 两类代表性产品的封装思路

Ondo Finance 的 OUSG 和 Hashport 的 USDY 是同一套逻辑的不同封装。OUSG 定位更偏机构：底层持有短期美债，通过赎回机制让 Token 价格贴近基金净值（NAV）。它的转账价格在净值附近小幅波动，像一只”链上货币基金份额”。USDY 则定位更偏生息稳定币形态：持有即对应有国债背书的份额，价格按规则每天小幅上行，可自由交易，看起来更像一个”会生息的美元”。

两者最大的工程差异在于”计息方式”的链上表达，这也是美债代币化最值得琢磨的技术点。一种叫 Rebase 方案：每次按利率增发少量 Token 给持有者，Token 单价不变，持有者手里的数量慢慢变多。另一种叫单价累积方案：保持 Token 总量不变，让 Token 对 USD 的单价每天上升一点点。

3. 两种计息方案为什么不一样

Rebase 方案的巧妙之处在于它保持了 Token 单价恒定。这对 DeFi 集成非常友好：一个交易对里如果 Token 单价恒定，做市商不需要频繁调整头寸，借贷协议也不用处理”抵押品数量在变”的麻烦。但它有个代价——持有者的余额在变，钱包里显示的 Token 数量每天都在涨，记账和税务处理都更复杂。

单价累积方案反过来：Token 数量不变，单价每天涨。它记账简单，钱包显示”你有 100 个，今天每个值 1.0003 美元”，直观清晰。但它在 DeFi 里更别扭——交易对的对手方价格每天都在漂移，借贷协议的清算逻辑要专门适配”抵押品单价在变”的情况。所以你看到 USDY 这类”价格上行”产品最接近稳定币体验，但它的 DeFi 组合能力相对弱一些。这是一个典型的工程权衡：没有谁更好，只有更适合哪种使用场景。

4. 赎回与限制：被低估的工程细节

很多人只看”计息”觉得简单，真正复杂的是赎回。OUSG 的赎回通常有最低额度和 T+1 结算——你想把 Token 换回法币，不是即时到账，而是要等托管方在现实系统里完成国债变现和资金划转。USDY 面向散户更灵活，但同样有自身的锁定和合规约束。这些延迟不是技术缺陷，而是因为底层资产（国债）的流动性有其自身的结算节奏，链上 Token 再快，也快不过托管方在现实金融系统里的操作速度。

另一个常被忽略的点是估值数据源。链上美债的价格不靠 AMM 自动发现，而是依赖每日净值快照——由托管方或管理员把底层资产的估值写入合约。这个”写值”动作本身就是一处信任点：如果写值出错或被操纵，链上价格就会偏离真实净值。所以合规 RWA 通常会配合第三方审计和独立数据源，把单点信任尽量分散。

**• **赎回限制：机构产品有最低额+锁定期，散户产品更灵活但有自身约束

**• **托管安全：底层资产由托管方保管，合约无法替代链下保管责任

**• **合规范围：美债类代币化产品被定性为证券，需满足特定法规，仅限特定投资者

**• **估值数据源：价格依赖每日净值快照，而非链上 AMM，写值动作是信任点

5. 链上美债的真正增量在哪里

把链上美债和传统基金放在一起看，它们的差异不在”底层资产”（都是美债），而在”资产所在的环境”。传统基金里的国债份额，只能在基金公司的系统里看、在交易时段里动；链上份额则进入了一个由智能合约构成的可编程世界。

🏦 底层：都持有美国国债（SPV / 货币基金） ↓

💱 交易：链上凭证 7x24 运行；传统基金仅交易时段 ↓

🔗 集成：链上凭证可进合约生态；传统基金不能 ↓

🛡 合规：链上凭证限特定投资者；传统基金条件不同

这种”进入合约生态”的能力，是传统金融系统难以低成本提供的。一笔国债份额第一次能在链上获得”被合约自动组合”的能力——拿去抵押、做池子、当衍生品标的，全部由代码自动执行。这才是链上美债区别于传统货基的本质，也是它被持续采用的根本原因。

✅ 美债代币化 = SPV 持债 + 链上份额 Token（OUSG / USDY 为代表）

✅ 封装逻辑：把国债操作逻辑（转让/计息/赎回）搬到链上

✅ 计息二选一：Rebase 增发（单价恒定） or 单价上行（数量恒定）

✅ 赎回受底层资产结算节奏约束，链上速度快不过托管方

✅ 技术增量：进入合约生态，获得被合约自动组合的能力
